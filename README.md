# Accident Threat Zone KNN Prototype

This prototype classifies road accident risk zones using K-Nearest Neighbors (KNN), shows the zones on Google Maps, and decides what medical supplies to alert based on sensor data.

## Files

- `accident_knn_system.py` - trains the KNN model, predicts red/blue/green zones, chooses medical supplies, and writes map data.
- `accident_sensor_data.csv` - sample accident and sensor dataset.
- `medical_supply_houses.csv` - sample medical supply house locations and available supplies.
- `map.html` - Google Maps visualization for accident threat zones.
- `map_data.json` - generated by the Python script.

## Run

Install dependencies:

```powershell
pip install pandas scikit-learn
```

Run prediction:

```powershell
python accident_knn_system.py
```

Start a local server:

```powershell
python -m http.server 8000
```

Open `http://localhost:8000/map.html` in a browser. Replace `YOUR_GOOGLE_MAPS_API_KEY` inside `map.html` with your real Google Maps JavaScript API key.
